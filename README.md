# United Real Estate Philadelphia — Agent Onboarding Portal

Premium SaaS-style agent recruiting and onboarding experience for United Real Estate Philadelphia.

## Features

- **Homepage** focused on economic advantage vs traditional brokerages (KW, HomeSmart, Compass, RE/MAX)
- **Brokerage comparison tool** with illustrative presets and editable assumptions
- **Commission calculator** (estimates only)
- **Onboarding Center** — 7-step progress dashboard with checklists (localStorage)
- **Technology, Leads, First 30 Days, Training** sections
- **Recruiter dashboard** (access code gated) — progress only, no private agent PII
- Mobile-responsive, Stripe/HubSpot-inspired product UI

## Quick start

Open `united-onboarding.html` in a browser (or serve locally):

```bash
python3 -m http.server 8765
# then visit http://localhost:8765/united-onboarding.html
```

## Files

| File | Description |
|------|-------------|
| `united-onboarding.html` | Full portal (single-file HTML/CSS/JS) |
| `onboarding-dashboard.html` | Standalone onboarding center view |

## Notes

- All commission figures are **estimates**. Confirm terms with United Real Estate Philadelphia.
- Recruiter demo access code: `UNITED`
- No private agent data is exposed on the public portal.
- Program availability, fees, and offerings are subject to change.
